# MyLove Graph

**Визуальная карта связей между всеми персонажами и NPC в SillyTavern.**

> *«Любовь — это игра. Сыграем?»*

MyLove Graph превращает ваш состав в живой граф отношений: кто в кого влюблён,
кто кому доверяет и кто кого не выносит. Живёт за плавающей кнопкой-сердцем.

**Карта не рисуется заранее — её пишет сама ролевая.** Персонаж появляется на
доске в тот момент, когда впервые выходит на сцену, а связи между героями
начинаются с едва заметной искры и по ходу сюжета крепнут, меняют цвет и
складываются окончательно.

## Возможности

- **Режим истории** — доска заполняется вслед за вашей ролевой, а не
  вываливается целиком в первую же секунду:

  | Стадия | Что значит | Как выглядит |
  | --- | --- | --- |
  | *искра* | двое всё чаще оказываются в одной сцене | короткий отрезок со светящимся кончиком |
  | *крепнет* | связь набирает силу | линия тянется дальше к собеседнику |
  | *связь* | сложилась | линия смыкается и разгорается |

  Души появляются, когда впервые заговорят или когда их назовут по имени. Тип
  связи решает то, что между героями происходит: дружба, ставшая романом, и на
  доске станет романом, а пара, о которой больше никто не пишет, потихоньку
  остывает.
- **Силовой граф отношений** на canvas — плавно и с парой персонажей,
  и с парой сотен.
- **Четыре типа связей**, каждый закодирован и цветом, и рисунком линии, чтобы
  оставаться различимым на маленьком экране:

  | Связь | Цвет | Линия |
  | --- | --- | --- |
  | Любовные / Романтические | ярко-розовый `#ff2d78` | сплошная, с бегущим «сердцебиением» |
  | Близкие | фиолетовый `#b46bff` | сплошная, тоньше |
  | Дружелюбные / Нейтральные | бирюзовый `#4fd6c8` | пунктир |
  | Напряжённые / Негативные | оранжевый `#ff6a3d` | точки |

- **Сила (1–100) и направление** у каждой связи — взаимная или односторонняя,
  для безответных чувств. Плюс произвольная подпись («тайно», «заклятые враги»…).
- **Все на одной доске**: карточки персонажей, ваша персона, участники групп и
  NPC, у которых карточки никогда не было.
- **Плавающая кнопка-сердце** — перетащите куда угодно, она прилипнет к
  ближайшему краю и запомнит место: и после поворота экрана, и когда вылезет
  клавиатура.
- **Панель BASIS** показывает Привязанность / Преданность / Напряжение
  выбранного персонажа, посчитанные по его связям.
- **Два языка**: английский (по умолчанию) и русский, переключаются с панели
  инструментов или из карточки настроек.
- **Сначала мобильные**: нижние шторки вместо всплывающих меню, панель
  инструментов, которая переносится по строкам вместо того, чтобы уезжать за
  край, меню, привязанные к *видимой* части экрана (с учётом полосы браузера и
  клавиатуры), зум щипком, ограниченный pixel ratio и цикл отрисовки, который
  останавливается, как только ничего не двигается.
- **Импорт и экспорт** всего графа в JSON.

## Установка

В SillyTavern: **Extensions → Install extension**, вставьте

```
https://github.com/jellysilly/ST-MyLove-graph
```

Или вручную:

```bash
cd SillyTavern/public/scripts/extensions/third-party
git clone https://github.com/jellysilly/ST-MyLove-graph MyLoveGraph
```

Затем перезагрузите SillyTavern.

## Как пользоваться

Открыть граф можно с плавающего сердца, из меню расширений («волшебная
палочка»), кнопкой **Открыть граф** в Extensions → MyLove Graph или командой
`/mylove`.

| Жест | Что делает |
| --- | --- |
| Тап / клик по узлу | Выбрать и открыть карточку |
| Двойной тап по узлу | Редактировать |
| Тап по связи | Выбрать связь |
| Двойной тап по связи | Редактировать связь |
| Перетаскивание узла | Переместить (позиция сохраняется) |
| Перетаскивание фона | Панорамирование |
| Колесо / щипок | Масштаб |
| Двойной тап по фону | Вписать всё в экран |

**Панель инструментов:** синхронизация · добавить (NPC, группа, синхронизация) ·
новая связь · хроника · вписать · перестроить схему · фильтры · данные
(импорт/экспорт/очистка) · язык.

Когда **режим истории** включён (а он включён по умолчанию), граф начинается
пустым и заполняется по ходу игры: хроника читает каждое новое сообщение,
выводит душу на доску в момент её первого появления и выращивает связи между
теми, кто снова и снова оказывается в одной сцене. Панель BASIS показывает, как
далеко хроника прочитала: глава, сообщения и сколько связей ещё зреет.

Выключите режим истории (или нажмите **Синхронизировать персонажей**) — и
получите прежнее поведение: все карточки плюс ваша персона разом, а связи вы
рисуете сами. Удалённая в SillyTavern карточка из графа **не** исчезает — узел
помечается пунктирным кольцом, чтобы связи вокруг него уцелели.

### Как хроника читает сцену

- **Кто в ней** — тот, кто говорит, плюс все имена из состава, найденные в
  тексте (падежи тоже: *Борису* и *Бориса* оба находят Бориса). Если история
  зовёт кого-то прозвищем, впишите его в поле *Другие имена* в карточке узла.
- **Что происходит** — небольшой словарь основ (русский и английский) голосует
  за любовь / близость / дружбу / напряжение. Никаких запросов к модели: пара
  миллисекунд на сообщение и работа без сети.
- **Сколько это весит** — назвать кого-то по имени весит больше всего, два имени
  в одном сообщении — меньше, просто отвечать друг другу — меньше всего. Одно
  слово не решает ничего: связь складывается из десятков сцен.
- **Кто тянется первым** — если о другом всё время вспоминает только один из
  двоих, связь рисуется односторонней. Безответные чувства проявляются сами.

Всё, что вы правите руками, остаётся вашим: хроника перестаёт управлять такой
связью и помечает её как *вашу*. В карточке связи есть кнопка вернуть её обратно
под управление истории.

## Настройки

Находятся в **Extensions → MyLove Graph**.

| Настройка | Что делает |
| --- | --- |
| Язык | Английский или русский |
| Выращивать связи из чата | Режим истории вкл/выкл |
| Только те, кого встретила история | Держать на доске лишь тех, кто уже появился |
| Считать имена в тексте | Учитывать и упоминания, а не только реплики |
| Остывание забытых связей | Связи, о которых больше не пишут, медленно гаснут |
| Темп | *Медленно*, *Ровно* или *Вихрем* — как быстро наливается связь |
| Перечитать чат | Пересобрать все связи истории с самого начала чата |
| Забыть историю | Стереть всё, что написала хроника (ручные связи останутся) |
| Плавающая кнопка-сердце | Показать или скрыть кнопку |
| Показывать в меню расширений | Пункт в меню «волшебной палочки» |
| Анимации | Пульсация, блики и сердцебиение вдоль романтических связей |
| Показывать имена / аватары / изогнутые связи | Что рисуется на доске |
| Автоматически добавлять новых персонажей | Держать доску в курсе списка карточек |
| Лёгкий режим | *Авто* (включён на сенсорных), *Всегда включён*, *Выключен* |
| Сбросить позицию сердца | Вернуть кнопку в угол |

**Лёгкий режим** снижает предел pixel ratio, убирает проходы свечения и
останавливает покадровую анимацию связей. На телефоне включён по умолчанию.

Анимации также учитывают системную настройку `prefers-reduced-motion`.

## О производительности

- Цикл отрисовки полностью останавливается, когда схема улеглась и ничего не
  анимируется; взаимодействие запускает его снова. Открытое неподвижное окно
  не стоит ничего.
- Свечение рисуется широкой полупрозрачной обводкой, а не `shadowBlur` —
  на мобильных GPU это в разы дешевле.
- Отталкивание работает как `O(n²)` до 120 узлов и переходит на
  пространственную сетку выше.
- Pixel ratio ограничен 2.5 (1.75 в лёгком режиме).

## Данные

Всё хранится в настройках самого SillyTavern, в
`extension_settings.mylove_graph` (то есть путешествует с вашим профилем);
если это хранилище недоступно — в `localStorage`.

Экспорт выглядит так:

```json
{
  "format": "mylove-graph",
  "version": 2,
  "nodes": [
    { "id": "char:seraphina.png", "kind": "char", "name": "Seraphina",
      "avatar": "seraphina.png", "role": "", "aliases": "", "note": "",
      "color": "", "x": 12.4, "y": -88.1, "pinned": false,
      "origin": "story", "seen": 42 }
  ],
  "edges": [
    { "id": "e:...", "a": "char:seraphina.png", "b": "npc:...",
      "type": "love", "strength": 82, "dir": "a2b", "note": "безответно",
      "origin": "story", "progress": 64, "locked": false, "hits": 19,
      "since": 51, "lastAt": 128 }
  ]
}
```

`kind` — это `char`, `npc` или `persona`. `dir` — `both`, `a2b` или `b2a`.
`origin` — `story` для всего, что написала хроника, и `manual` для остального;
`progress` — насколько связь истории уже сложилась (0–100), `seen` и `since` —
номера сообщений, с которых всё началось. Экспорт первой версии импортируется
по-прежнему — его связи просто приходят уже сложившимися. Импорт заменяет
текущую доску, так что сначала сделайте экспорт, если нужна резервная копия.

## Для тех, кто любит покопаться

`window.MyLoveGraph` отдаёт `open()`, `close()`, `toggle()`, `sync()`,
`export()`, `settings()`, `save()` и `instance()` (живой движок canvas), а ещё
саму хронику:

```js
MyLoveGraph.story.status();    // { applied, total, chapter, sparks, settled }
MyLoveGraph.story.read();      // прочитать всё новое в чате
MyLoveGraph.story.rebuild();   // перечитать чат с начала
MyLoveGraph.story.forget();    // стереть все связи истории
```

Пока окно открыто, на `<html>` висит класс `mlg-open` — удобно для своего CSS.

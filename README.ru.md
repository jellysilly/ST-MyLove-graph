# MyLove Graph

**Визуальная карта связей между всеми персонажами и NPC в SillyTavern.**

> *«Любовь — это игра. Сыграем?»*

MyLove Graph превращает ваш состав в живой граф отношений: кто в кого влюблён,
кто кому доверяет и кто кого не выносит. Живёт за плавающей кнопкой-сердцем,
работает на телефоне, не сажая батарею, и говорит на английском и русском.

[English version](README.md)

---

## Возможности

- **Силовой граф отношений** на canvas — плавно и с парой персонажей,
  и с парой сотен.
- **Четыре типа связей**, каждый закодирован и цветом, и рисунком линии, чтобы
  оставаться различимым на маленьком экране:

  | Связь | Цвет | Линия |
  | --- | --- | --- |
  | Любовные / Романтические | ярко-розовый `#ff2d78` | сплошная, с бегущим «сердцебиением» |
  | Близкие | фиолетовый `#b46bff` | сплошная, тоньше |
  | Дружелюбные / Нейтральные | бирюзовый `#4fd6c8` | пунктир |
  | Напряжённые / Негативные | оранжевый `#ff6a3d` | точки |

- **Сила (1–100) и направление** у каждой связи — взаимная или односторонняя,
  для безответных чувств. Плюс произвольная подпись («тайно», «заклятые враги»…).
- **Все на одной доске**: карточки персонажей, ваша персона, участники групп и
  NPC, у которых карточки никогда не было.
- **Плавающая кнопка-сердце** — перетащите куда угодно, она прилипнет к
  ближайшему краю и запомнит место.
- **Панель BASIS** показывает Привязанность / Преданность / Напряжение
  выбранного персонажа, посчитанные по его связям.
- **Два языка**: английский (по умолчанию) и русский, переключаются с панели
  инструментов или из карточки настроек.
- **Сначала мобильные**: нижние шторки вместо всплывающих меню, панель
  инструментов в две строки, зум щипком, ограниченный pixel ratio и цикл
  отрисовки, который останавливается, как только ничего не двигается.
- **Импорт и экспорт** всего графа в JSON.

## Установка

В SillyTavern: **Extensions → Install extension**, вставьте

```
https://github.com/jellysilly/ST-MyLove-graph
```

Или вручную:

```bash
cd SillyTavern/public/scripts/extensions/third-party
git clone https://github.com/jellysilly/ST-MyLove-graph MyLoveGraph
```

Затем перезагрузите SillyTavern.

## Как пользоваться

Открыть граф можно с плавающего сердца, из меню расширений («волшебная
палочка»), кнопкой **Открыть граф** в Extensions → MyLove Graph или командой
`/mylove`.

| Жест | Что делает |
| --- | --- |
| Тап / клик по узлу | Выбрать и открыть карточку |
| Двойной тап по узлу | Редактировать |
| Тап по связи | Выбрать связь |
| Двойной тап по связи | Редактировать связь |
| Перетаскивание узла | Переместить (позиция сохраняется) |
| Перетаскивание фона | Панорамирование |
| Колесо / щипок | Масштаб |
| Двойной тап по фону | Вписать всё в экран |

**Панель инструментов:** синхронизация · добавить (NPC, группа, синхронизация) ·
новая связь · вписать · перестроить схему · фильтры · данные
(импорт/экспорт/очистка) · язык.

При первом открытии граф подтягивает все карточки персонажей и вашу персону.
Дальше новые карточки добавляются сами (отключается опцией *Автоматически
добавлять новых персонажей*). Удалённая в SillyTavern карточка из графа **не**
исчезает — узел помечается пунктирным кольцом, чтобы связи вокруг него уцелели.

## Настройки

Находятся в **Extensions → MyLove Graph**.

| Настройка | Что делает |
| --- | --- |
| Язык | Английский или русский |
| Плавающая кнопка-сердце | Показать или скрыть кнопку |
| Показывать в меню расширений | Пункт в меню «волшебной палочки» |
| Анимации | Пульсация, блики и сердцебиение вдоль романтических связей |
| Показывать имена / аватары / изогнутые связи | Что рисуется на доске |
| Автоматически добавлять новых персонажей | Держать доску в курсе списка карточек |
| Лёгкий режим | *Авто* (включён на сенсорных), *Всегда включён*, *Выключен* |
| Сбросить позицию сердца | Вернуть кнопку в угол |

**Лёгкий режим** снижает предел pixel ratio, убирает проходы свечения и
останавливает покадровую анимацию связей. На телефоне включён по умолчанию.

Анимации также учитывают системную настройку `prefers-reduced-motion`.

## О производительности

- Цикл отрисовки полностью останавливается, когда схема улеглась и ничего не
  анимируется; взаимодействие запускает его снова. Открытое неподвижное окно
  не стоит ничего.
- Свечение рисуется широкой полупрозрачной обводкой, а не `shadowBlur` —
  на мобильных GPU это в разы дешевле.
- Отталкивание работает как `O(n²)` до 120 узлов и переходит на
  пространственную сетку выше.
- Pixel ratio ограничен 2.5 (1.75 в лёгком режиме).

## Данные

Всё хранится в настройках самого SillyTavern, в
`extension_settings.mylove_graph` (то есть путешествует с вашим профилем);
если это хранилище недоступно — в `localStorage`.

Экспорт выглядит так:

```json
{
  "format": "mylove-graph",
  "version": 1,
  "nodes": [
    { "id": "char:seraphina.png", "kind": "char", "name": "Seraphina",
      "avatar": "seraphina.png", "role": "", "note": "", "color": "",
      "x": 12.4, "y": -88.1, "pinned": false }
  ],
  "edges": [
    { "id": "e:...", "a": "char:seraphina.png", "b": "npc:...",
      "type": "love", "strength": 82, "dir": "a2b", "note": "безответно" }
  ]
}
```

`kind` — это `char`, `npc` или `persona`. `dir` — `both`, `a2b` или `b2a`.
Импорт заменяет текущую доску, так что сначала сделайте экспорт, если нужна
резервная копия.

## Для тех, кто любит покопаться

`window.MyLoveGraph` отдаёт `open()`, `close()`, `toggle()`, `sync()`,
`export()`, `settings()`, `save()` и `instance()` (живой движок canvas).
Пока окно открыто, на `<html>` висит класс `mlg-open` — удобно для своего CSS.

## Дизайн

Интерфейс следует языку постера *Love Potion*: почти чёрный фон, яркий
пурпурный свет, тонкие HUD-рамки со скобочными углами, моноширинные
микро-подписи и рукописный заголовочный шрифт. Шкалы BASIS и метки
`528 HZ` / `404-G` — оттуда же.
